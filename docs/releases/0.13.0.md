# Immersion 0.13.0

This release improves multistream layout, slow-player recovery, shared settings
and saved sessions, and chat preview performance.

## Workspace and player recovery

- Focus mode fills the column beside the focused stream before placing extra
  streams underneath. Resizing and refocusing preserve existing player frames.
- Queued full-player panes offer **Use standard embed** immediately. Switching
  removes the queued full-page job without reloading other streams.
- Player switches preserve pending play/pause requests. Embed fallback and full
  player retry restore keyboard focus to the pane header.
- Leaving Schedule unloads its iframe. Failed metadata becomes retryable after
  five seconds while retaining previously loaded information.

## Reliability and performance

- Saved sessions have stable IDs and serialized background mutations. Open tabs
  synchronize their session menus without autosaves replacing the shared list.
- Popup and tab settings use serialized field-level patches, retaining pending
  local edits and recovering the displayed values after a save failure.
- Preview requests share bounded queues. Removing a preview or closing its tab
  releases its request; work stops when its last consumer leaves.
- Chat previews inspect changed rows instead of repeatedly inspecting every
  retained preview. Front-inserted links still respect playback limits.
- Player observers ignore unrelated chat churn. Response readers enforce byte
  limits while streaming and respect cancellation.
- Retry controls show loading, prevent duplicate activation and retain keyboard
  focus. Profile-preview setting changes preserve unrelated media players.
- Removed unused styles, hidden controls, obsolete editor guards and orphaned
  fixtures. Workspace directory logic now has a separate owner.

## Packaging and validation

Both manifests take their version from `package.json`. Build checks verify
matching package/lockfile/manifest versions and exact ZIP inventories; browser
caches and stale assets are excluded.

Validation includes 77 unit tests; Chromium and Firefox workspace, full-player
and queued-fallback integration checks; installed Chromium cross-tab session and
popup settings checks; retry recovery; and package inventory checks. Firefox
fixture checks inject the extension scripts and do not claim an installed,
signed add-on test. The broader audit also includes focus geometry, incremental
preview cleanup and repeated workspace lifecycle checks.

The local cleanup benchmark reduced X/media row inspections from 1,200 to 20
for its fixed workload. This is an inspection count, not a measured live-stream
CPU improvement. Live playback was not proven in the anonymous profiling run.

## Install or roll back

Download the browser ZIP from the `v0.13.0` tag, reload the extension and refresh
Kick. The previous committed build is retained as `pre-v0.13.0` at commit
`367f9e0` for rollback; its browser ZIPs remain available from that tag.
